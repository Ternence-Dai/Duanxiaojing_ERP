# ERP 管理系统 · 桌面版

桌面版是一个轻量 Electron 壳：启动后在本机 127.0.0.1:17366 提供应用页面，
再打开窗口加载。之所以不用 `file://` 直接打开，是因为应用用相对路径加载
ES 模块，`file://` 下模块加载会失败，部分功能会降级报错。

## 数据存储

和网页版一致，数据保存在应用内的 localStorage（键 `textile_erp_v4_enterprise`），
只存在本机当前 Windows 用户下。端口固定为 17366 是为了保证每次启动都是
同一个本地源，数据不会“消失”。桌面版使用独立的数据目录（userData 目录
`ERP`），与浏览器里打开的网页版数据互不影响；如需在两边之间迁移
数据，请用应用内的导入/导出或备份功能。

## 重新打包（Windows x64 便携版）

在本目录运行（只需要 Node.js）：

```
node build-windows.cjs
```

脚本会下载官方 Electron Windows 运行时，把本目录的壳与仓库的网页应用
组装成 `ERP` 文件夹，并打包为仓库根目录的 `ERP-Windows-x64.zip`。
解压后双击 `ERP.exe` 即可运行，无需安装。

应用名称、zip 文件名与端口都在 `app.json` 里配置，壳代码不写死。

说明：便携版使用 Electron 默认图标，未做安装程序（NSIS）和代码签名；
Windows 首次运行可能出现 SmartScreen 提示，选择「仍要运行」即可。
